- 股票范围：2020-01-02 当天的历史主板股票列表，固定随机抽样24只，种子20201009；保留后来结束行情的股票，没有用今天存活股票替换。该固定池不包含2020年后上市股票。

- 原规则：实际导入上游 `enter.check_volume` 和 `turtle_trade.check_enter`，不是按README重新猜写。
- 改进假设：预先规定“放量上涨＋MA20高于MA60＋收盘价不低于MA20”，不进行参数搜索。它是否改善策略，由结果判断，不能以减少亏损认定已盈利。
- 所有规则统一要求250个有交易状态的历史日。指标输入删除零成交停牌占位行，成交量单位为股；复权历史以信号日原价锚定，避免未来复权改变金额阈值。
- 模拟本金3万元，单笔预算5000元，最多持有3只，计划持仓最多50%，每天最多新增1只；多个候选按截至信号日近20日成交额排序，股票代码作固定次级排序。
- 买入：当日收盘选股，提前确定整手数量和最高买入价，次日开盘尝试成交。最高价格为信号日收盘价加3%，超限不买。
- 卖出：分别比较买入后的第1、3、5个市场交易日开盘退出。收盘亏损达到3%的退出条件则下一交易日开盘尝试退出；停牌、开盘跌停会延后，3%不是损失上限。
- 费用：佣金万2.5、单次最低5元；双边过户费0.001%；卖出印花税0.05%；每边0.05%的模拟滑点作为额外费用。使用统一当前成本情景，并非历史费率逐日复刻。
- 公司行动：登记日持股取得权益，除权日计入应收，支付日转现金；现金分红按20%统一保守税率模拟。送转股在上市日前锁定。实际分红税的补扣时点、复杂配股与特殊结算尚未完整实现。
- 期末持仓计入净值，不强行卖掉；胜率只算完成平仓的交易。异常参考价、持仓缺失行情和缺失公司行动信息要标记警告。
- 分段：2020–2023研究，2024验证，2025留出；分段报告各自以3万元重启，便于区分市场阶段。2025结果已被本次查看，后续改动不能继续把它当作未见测试集。

## 重跑与扩大股票范围

在本目录的 PowerShell 中：

```powershell
# 原实验重跑：不修改参数，不重新下载。
& .\.venv\Scripts\python.exe -X utf8 .\run.py --output .\results\replay-v1

# 核对账户逻辑及未来数据隔离。
& .\.venv\Scripts\python.exe -X utf8 -m unittest -v test_engine

# 扩为300只同日起始历史随机样本；先下载，再明确指定新数据和新实验目录。
& .\.venv\Scripts\python.exe -X utf8 .\download.py --count 300
& .\.venv\Scripts\python.exe -X utf8 .\run.py --dataset .\data\pilot-2020-01-02-2025-12-31-n300-s20201009 --output .\results\sample-300
```

扩大下载有时间和网络请求成本。程序按股票顺序下载并缓存，失败记录在数据清单中；失败样本不自动换成其他股票，回放拒绝不完整的数据清单。源文件或数据变动后，程序要求使用新的结果目录，避免覆盖旧实验。

`download.py` 支持起止日，但当前报告的时间分段和主板涨跌停假设固定为2020–2025。若研究其他时期，先同时修改这些假设，不能只改下载日期。

## 现成回测工具与首版选择

[Backtrader](https://www.backtrader.com/docu/)提供订单、账户、费用和多股票回测能力；A股T+1、整手、历史涨跌停、公司行动仍需配置或扩展。本版采用一个可逐笔核对的小型日线账本，便于保留上游选股规则、处理分红应收和锁定送转股；简单开盘买卖和费用结果已与Backtrader作独立交叉检查。

这并不等于完整账户逻辑已获成熟框架或真实券商的全面验证。

## 下一轮怎么改进

1. 先扩大历史股票池并核查退市、停牌、公司行动；全市场评估需要逐日可用股票范围，不能一直沿用24只固定池。
2. 加入指数与相同股票池、相近仓位/换手的基准；分辨收益来自选股、市场整体变化还是交易次数变化。
3. 从已生成的费用和逐笔交易中定位亏损：跳空买入、持有期、交易次数、信号质量各自造成多少影响。
4. 每次只改变一个预先说明的规则，使用新的实验目录，严格区分研究、验证和最终未见数据。
5. 在规则账本可靠后再加入逻辑回归或LightGBM，与固定规则在相同股票池、成交条件、仓位和费用下比较。

当前实验没有机器学习训练或实盘交易，也不能证明长期胜率超过60%。日线无法还原盘口排队和盘中先后；特殊公司行动与退市现金结算仍是明确限制。质量警告为0也不代表数据及模拟规则完全无误。

## 主要文件

- `download.py`：历史日期股票池、日线、分红和下载清单。
- `signals.py`：过去数据截断、原规则调用、趋势过滤对照。
- `engine.py`：订单、现金、持仓、交易限制与公司行动账本。
- `run.py`：固定实验、分段比较、费用诊断与报告导出。
- `test_engine.py`：成交时序、T+1、涨跌停、费用、分红送转、期末持仓、未来信息隔离和独立框架检查。
