# V0.9监督过滤与冻结RL对照协议

2026-10-21。用户授权执行论文调研提出的简单监督过滤对照。本文件在提取新训练标签、拟合和生成新评估结果之前保存。当前采用V0.8。

## 固定范围

本轮用与既有RL相同的2022年度训练窗口及相同7个前收盘离散状态。这样不会把监督模型2022—2024训练和旧RL仅2022训练混成同样数据条件。跨年度扩展训练留待后续阶段。

V0.8已有V2收益门控和排序，本轮固定其预测、股票池及交易规则，只研究是否接受当前整批待买单。输入为广度档、市场5日收益档、暴露档、回撤档、组合浮盈亏档、最长持仓年龄档、待买数档。不增加股票代码、日期、未来结果或其他新特征。所有组继承V0.8原退出；不触发额外RL提前退出。

主比较四组：V0.8；固定规则（仅接受广度档为2、即广度不低于0.58的待买批）；简单监督过滤；原2022三种子固定投票的RL仅过滤。另原3种子RL仅过滤各自完整披露，不挑最好种子。原RL仍先按原动作集合投票，再保留取消买单位。

## 监督样本与拟合

先完整回放2022 V0.8基线，在每个前收盘状态捕获已排定的待买批次。批次标签来自该基线实际成交交易，按交易ID汇总其完成后的净利润与投入：next-open、现金/持仓/整手限制、停牌、涨跌停、止损/期限、费用和公司行动均由原引擎处理。未成交批不能记成成功或失败；任何未全平仓/权利未完成批标右删失。只有全部相关交易已完成、最后标签日期严格早于2023-01-01才参与训练。禁止改用收盘涨跌标签。

标签y=1当该批完成交易的合计净利润>0，否则0。它是基线状态分布下已成交批次的代理标签，不是接受/拒绝对未来资金、名额和机会成本的组合效用真值。拒单样本的排除条件包含未来成交信息，但仅用于定义条件标签；部署过滤不得据次日是否成交预先选择机会，评估必须保留全部真实排单/拒单流程。

只拟合一个模型：训练集StandardScaler + LogisticRegression，C=1、class_weight=None、solver=lbfgs、max_iter=2000。接受分数阈值固定0.5，不搜索超参、特征、种子或阈值；该分数未做独立概率校准，不等于盈利胜率。至少10个成熟批且正负类各2个是本轮算法拟合的最低条件，不是统计充分性保证；不足则如实记不可评估，不能事后降低门槛。

2022上游V2/V0.8年度模型最后训练标签必须早于2022年，核对其既有训练元数据。标签成熟时间、样本与模型、标准化和参数哈希保存；拟合并冻结监督模型之后才读取后续评估行情。三份既有Q表不更新。

## 固定回放

2022训练回放、2023、2024、2025、2023—2025连续及2026截至10月13日。每期3万元空账户，正常/双倍滑点独立完整撮合。4个主组×6时期×2成本=48账户，3个单种子RL诊断×6×2=36账户，总84。逐年重置与连续账户不相加。

接受率以各账户有待买单的每日批次为单位；订单接受数和实际成交数另列。状态随每个账户实际资金/持仓路径重算。披露训练批数、排除原因、正负类、系数，以及评估状态未在各训练样本中出现的机会比例。无待买单的空闲日不能充作大量分类样本。

同一年份、相同观测量不代表两种算法训练分布/目标完全相同：RL经过探索轨迹和净值奖励，监督模型来自基线轨迹和批次盈亏标签；结论仅针对这组固定实现，不把表现差异归因为算法类别本身。

## 核验与验收

训练基线与既有2022账本一致；评估V0.8、RL固定投票及3单种子与既有动作拆分结果逐CSV一致，共60个参考场次。独立重建导出账本、训练标签、模型重载分数与动作日志，确认标准化只用训练样本、标签已成熟、策略评估无更新。原输入、Q表、DAY1、运行模型冻结、RQAlpha连接冻结均验证原哈希。

主组沿用既定门槛：2023—2025连续与2026两个已看历史时期，正常收益均超过V0.8、回撤不恶化、双倍滑点收益更高，且数据/账本通过，才记历史研究达标。不按本次结果改门槛，不挑种子，不自动替换V0.8。没有同暴露随机对照，不能宣称已排除单纯减少仓位的解释。

本轮不使用后续年份选择阈值，因此不设新的调参验证集；2023—2026此前已看过，只称固定参数的已看历史评估，不能称独立盲测。真正泛化仍需以后冻结并前瞻封存。
