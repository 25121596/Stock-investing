# V0.9强化学习研究候选：仅2022年原型

2026-10-21。按用户要求，仅用2022年的行情轨迹更新强化学习参数；不利用2023年以后的收益选参数、种子、训练轮数或动作。当前运行模型仍为V0.8。

## 原型范围

使用轻量表格Q-learning，不安装深度学习依赖。上游保持V0.8已经存在的逐年预测/排序和门控；2022年的上游模型在2022年前训练，因此“仅2022训练”特指本轮RL参数，不是声称上游模型也只用2022。已有历史研究涉及后续年份，因此后续只能称冻结历史留出评估，不能称未见盲测。

统一每日组合动作：0跟随V0.8；1跳过前一收盘已排定的买单；2在次开盘尝试提前退出全部旧持仓；3同时跳过并退出。无买单/无持仓时屏蔽无意义动作；不会产生V0.8之外的新股票或提高预算/风险上限。原硬性止损/到期退出仍可触发；不能通过动作撤销原安全退出。

状态来自前一交易日收盘：广度档、市场5日收益档、持仓暴露档、账户回撤深度档、组合浮盈亏档、最长持仓年龄档、待买数量。固定离散边界，不含日期、股票代码、未来价格或已知盈利交易身份。

奖励为每个实际收盘的扣费净值对数变化，减去0.25乘以非负回撤深度的新增部分，整体乘10000；净值含未实现盈亏和应收款，不重复扣费。动作在前一收盘状态确定，只影响下一开盘；Reward在其后的收盘才可用于更新。环境通过VerifiedV08Replay继承原执行，不重写撮合循环。质量问题立即失败，不当作惩罚继续。

Q-learning固定alpha=0.1、gamma=0.95、训练200轮、epsilon从0.30线性降到0.05。3个固定种子2026102101/02/03全部保存和披露。评估只使用状态/动作至少访问10次的值，未知状态默认跟随V0.8，同值优先较小动作。部署候选为预先固定的三种子动作多数投票，同票优先跟随/较小动作，不能挑表现最好的种子。

训练只给引擎2022日期、2022行情、2022信号/广度/波动率；2022外的公司行动允许保留身份资料，但只有训练年相关登记/交付才会执行，不能用以后事件过滤股票。最后一个交易日按相同规则标记期末净值，不强行清仓，不读取2023日线来补最后一个奖励。200次重放是一条历史轨迹的重复，不是200个独立年份。

## 固定评估

训练后保存Q表及哈希，再首次读取后续评估期数据。逐期比较2022训练期、2023、2024、2025、2023—2025连续账户、2026截至10月13日；每期同样3万元初始账户，正常与双倍滑点。逐年重置与连续账户分开，不能相加。基线、3种子和固定投票都保留，数据失败不补种子。

首先要求：被动动作0与V0.8逐笔/逐日一致；T+1/费用/停牌/跌停及质量拦截不被绕过；未来价格改动不能改变更早状态或动作；保存重载策略一致；执行评估不得更新Q表。

模型验收仍须收益和回撤综合超过V0.8：固定投票在2023—2025及2026两个留出时期正常收益更高、回撤不恶化、压力收益更高，且账本/数据质量通过，才标记历史研究达标。2022训练期盈利不算泛化证据。这个原型主要检验学习环境和跨年份行为，不能保证达标，也不自动替换DAY1/RQAlpha运行模型。
