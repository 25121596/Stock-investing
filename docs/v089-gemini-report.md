## 二、瓶颈诊断与结构性拖累量化分析

在 A 股小资金量化模型的长期演进中，V0.8.8 架构确立了“高爆发广度买入扩容 + 模式限制日内止损”的有效范式，但其净收益始终被压制在 +68% 附近，无法突破 +90%~+120% 核心目标区间。经过对底层逐日账本与头寸分布的深度穿透审计，确立了导致收益压制的 **四重结构性拖累（Structural Drags）**：

```
+----------------------------------------------------------------------------------------------------+
|                                    85% 现金拖累瓶颈根因透视                                          |
+----------------------------------------------------------------------------------------------------+
| 1. 隔夜闲置现金零利率拖累 (Cash Idle Drag)                                                         |
|    - 账户平均闲置资金比例高达 85.01%，全周期 70.45% 的交易日处于零仓位状态。                            |
|    - 闲置现金在防御期未产生任何生息回报，造成严重的复利资本流失。                                   |
|                                                                                                    |
| 2. 广度门控的二元硬截断 (Regime Hard-Clamping)                                                     |
|    - 2022–2025 年间，市场广度 < 0.58 的防御及修复期天数占比达 63.5%（2026 年达 70.9%）。             |
|    - 原模型在广度 0.48~0.58 的“市场底部反转修复区”实施一刀切阻断，错失优质动量龙头的左侧建仓机会。  |
|                                                                                                    |
| 3. 静态单笔预算稀释效应 (Fixed Budget Compounding Dilution)                                        |
|    - 初始 30,000 元本金设定单笔上限 7,500 元（占比 25%）。                                           |
|    - 随着账户权益成长至 50,000~57,000 元，固定 7,500 元预算使单笔仓位占比稀释至 13% 以下，          |
|      高胜率主升浪交易无法带动整体净值实现几何级复利。                                               |
|                                                                                                    |
| 4. 槽位饥饿与资金周转停滞 (Slot Starvation & Stale Holding)                                        |
|    - 原 10 天固定持有期在震荡与防御期使得有限仓位被过长锁定，资金轮动速度偏慢，降低了资金年化利用率。|
+----------------------------------------------------------------------------------------------------+
```

### 详细量化指标：
- **平均现金闲置率**：85.01%（日均现金余额占 NAV 比例）。
- **零持仓交易日占比**：70.45%（813 / 1,154 个交易日完全空仓）。
- **非强势广度天数占比**：2022–2025 年 969 个交易日中，广度 $< 0.58$ 的交易日共 615 天（占比 63.5%）；2026 年 185 个交易日中，广度 $< 0.58$ 的交易日达 131 天（占比 70.9%）。
- **预算稀释倍数**：在 2025 年底账户净值达到 57,000 元时，原 7,500 元预算的资金利用率较初始阶段折损了 **47.4%**。

### 3.1 隔夜闲置现金自动化生息增强机制（Automated Overnight Cash Overlay）
在真实 A 股机构与高净值账户管理中，未入市资金可通过国债逆回购（GC001/R-001）或券商保证金生息产品实现低风险流动性增厚。
- **生息模型参数**：基准年化收益率 $r = 2.2\%$，全年设定 242 个交易日。
- **单日收益率公式**：
  $$y_{\text{daily}} = \frac{r}{242.0} = \frac{0.022}{242.0} \approx 9.090909 \times 10^{-5} \text{ / 交易日}$$
- **每日计息与入账逻辑**：
  在每日收盘结算、持仓市值盯市前，对账面可用现金进行线性计息：
  $$\text{Interest}_t = \text{Cash}_t \times y_{\text{daily}}$$
  $$\text{Cash}_t \leftarrow \text{Cash}_t + \text{Interest}_t$$
  $$\text{Accumulated\_Cash\_Yield} \leftarrow \text{Accumulated\_Cash\_Yield} + \text{Interest}_t$$
- **微观结构保真性**：生息仅发生在真实账面剩余可用现金上（扣除当日买入成交及所有手续费后）。已冻结挂单资金与应收股利不重复计息，杜绝虚假资金凭空膨胀。

### 3.2 广度修复区高确信自适应门控（Multi-Regime Recovery Zone Gating）
原 V0.8.8 仅在广度 $\ge 0.58$ 时开仓。为提高资金利用效率，同时杜绝在弱势熊市中频繁遭受假突破伤害，引入非对称双门槛自适应门控机制（`AdaptiveGatekeeperGemini`）：
- **区间状态划分**：
  1. **标准强势牛市区间（$\text{Breadth} \ge 0.58$）**：
     - 放行条件：预期净收益 $\text{pred\_net\_return\_v2} \ge 0.0030$。
     - 仓位与容量：允许最多打满 4 龙头席位；每日依据爆发广度动态买入 2~3 只标的。
  2. **广度修复试探区间（$0.48 \le \text{Breadth} < 0.58$）**：
     - **高确信准入要求**：个股预期净收益门槛大幅收紧至 $\text{pred\_net\_return\_v2} \ge 0.0050$（严格筛选出具有极端动量反转Alpha的标的）。
     - **严格容量阻尼**：每日最多准入 1 只买单，且该区间持仓上限严格限制为 $\le 2$ 只。
  3. **空头防守防御区间（$\text{Breadth} < 0.48$）**：
     - 坚决阻断全部次日开盘新买单（0 买入，0 容忍），100% 资金回退至现金生息。

### 3.3 4 席位龙头重仓与下限保障净值复利预算（Floor-Capped Compounding Budget）
打破静态 7,500 元预算约束，设计具备下限安全垫与风险上限隔离的动态净值复利公式（`compute_dynamic_compounding_budget`）：
- **核心计算公式**：
  $$\text{eff\_budget} = \max\left(7500.0, \min\left(15000.0, \left(\frac{\text{NAV} \times 0.90}{4}\right) \times 1.04\right)\right)$$
- **参数工程学设计哲学**：
  - `slots = 4`：将总席位收敛至 4 只集中龙头（单股名义权重约 22.5%~25%），克服 5 席位资金过于分散、3 席位易触发“槽位饥饿”的缺陷。
  - `target_exposure = 0.90`：保留 10% 的流动性缓冲现金，杜绝极端行情下的强制平仓。
  - `budget_multiplier = 1.04`：提供 4% 的微观交易摩擦与整手溢价缓冲，确保可买入股数顺利跨过 100 股整手门槛。
  - `min_budget = 7500.0`：**下限保障**。当账户早期或遭遇回撤时，预算绝不下调至 7,500 元以下，确保零售小资金始终具备买入中高价白马股（如 70 元股价）的基本整手能力。
  - `max_budget = 15000.0`：**绝对上限隔离**。单只股票持仓金额被强制封顶在 15,000 元以内，严防后期单次暴跌引发致命回撤。
- **整手向下取整与佣金扣除约束**：
  $$\text{Quantity} = \left\lfloor \frac{\max\left(0, \min(\text{eff\_budget}, \text{Cash}) - \text{min\_commission}\right)}{\text{LimitPrice} \times (1 + \text{commission} + \text{transfer\_fee} + \text{slippage})} \right\rfloor \div 100 \times 100$$
  若计算所得整手数 $< 100$ 股，触发 `lot_size_or_budget` 拦截，杜绝资金透支与零股违规。

### 3.4 动态紧凑持有周期与日内模式限制触价止损（Compact Horizon & Touch Stopping）
- **动态紧凑周期（Compact Dynamic Horizons）**：
  - 强势市场（前一日广度容量 $\ge 2$）：持有期设定为 **11 天**，充分捕获主升浪趋势动量。
  - 常态/防御市场（前一日广度容量 $< 2$）：持有期缩短为 **7 天**，加速低波震荡期资金周转（加快约 15%~30%），减少钝化持仓对流动性的锁定。
- **模式限制日内触价退出（`TouchModeStoppingGemini(mode='sl')`）**：
  - **仅允许日内止损生效**：当且仅当持仓股票在盘中击穿止损线（-3%）时，立刻以触碰价并追加 10 bps 惩罚滑点强制平仓出局。
  - **止盈与移动浮盈底保护**：维持收盘价判定并于次日早盘集合竞价退出，杜绝盘中虚假尖刺洗盘导致强势波段龙头过早下车。
  - **严格 T+1 与天地板避险防线**：若买入当日盘中触碰止损，受限于 T+1 铁律必须锁定至次日；若同一交易日同时触及止损与止盈线，状态机严格优先执行止损，杜绝后见之明偏误。
