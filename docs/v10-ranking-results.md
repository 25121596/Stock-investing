# V0.8.1研究候选：五个方案均未达到预定升级要求

命名已按用户约定调整；旧实验编号V0.10／V10及存储路径仅用于追溯。当前已采用最新版仍是V0.8，规则见[版本命名](../VERSIONING.md)。

2026-10-21。本轮实测已结束，当前没有可以按事前标准替代V0.8的候选。原V0.8冻结权重、DAY1和RQAlpha运行队列不变。

机制不是增加杠杆或放宽门槛，而是修正“全截面前20%同一标签”与实际只买前1/2名之间的差距。先做标签分辨率/顶部损失截断的2×2消融，三者未过后，按照事前写定的条件增加交叉熵排序和直接收益回归。参数、试验上限和验收标准见[事前协议](v10-ranking-protocol.md)。

所有数字均为3万元同风险账户扣费后累计收益，无现金利息。2026截至10月13日，所有历史均已查看。双倍滑点也重跑完整路径，五个候选在2026均未超过受压V0.8。不能把只在旧期明显改善的结果包装成全面升级。

## 已经确认的研究价值与限制

- 顶部标签/损失的调整对账户表现影响很大，旧期三个方案同时提高收益并降低回撤；这比只报告排序IC提高更有实际意义。
- 更强的旧期成绩没有带来2026领先，说明同一特征集上改损失函数还不能稳定解决行情依赖，不能将方法名称或更先进的目标当作盈利保证。
- 最接近全面达标的是只聚焦顶部的版本，2026净利润比基线少150.08元，回撤更小；但它改变了多笔股票选择及后续持仓路径，不能说只修一笔交易就能达标，更不能围绕已知赢家继续挑参数。
- 仅25个新年度权重（5候选×5年）就属于一次多方案研究；结果应降格为开发筛选证据，而非独立验证。没有基于年号切换模型、没有按既知获利股改排序、没有事后调混合权重。

## 完整性与审查

1. 五年原V0.8保存权重重新推断298754个分数，与原分数一致。训练行数、37特征矩阵及原相关度标签哈希逐年与原年度记录一致。
2. 24个策略/压力账户和39个有效共享随机账户，共63个有效导出账户、7862笔成交，已从CSV独立重建现金、股份、税费和每日净值并对账通过。25份年度模型权重和训练时间边界核对通过。
3. 共请求40个共享随机账户；旧期一个账户因中航机电吸收合并后旧代码缺报价被拦截。旧期随机统计是19/20有效账户的条件分布，2026是20/20；不是全量通过，不补种子。固定门控使所有候选共享同一随机对照，不能算成多个独立实验。
4. Luna独立审查发现原runner的阶段条件可能把“数据/账本质量失败”误作“有效但未达标”，从而进入第二阶段。实际第一阶段16个基线/候选/压力场次全部完整、质量0且账本通过，缺陷没有影响这轮进入第二阶段的合法性。原v1和运行快照保留；已新增修正版`run_v10_rank_objectives_v2.py`，未来若第一阶段缺项、质量失败、审计失败或判定不完整，一律拦截。没有为了重获合格结果而重训。
5. 导出核验首次因CSV默认浮点解析改变半分钱边界而报错；改用round_trip恢复原始浮点数后全部费用匹配。未修改原成交费用，也未放宽允许误差。此处保留的是原冻结费用约定，不是声称原二进制浮点实现等同于十进制货币计算。
6. 训练/阶段条件与相关执行回归检查通过；保护的未来记录、权重冻结和外部连接冻结哈希均保持不变。
