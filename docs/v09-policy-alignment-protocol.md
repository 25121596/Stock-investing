# V0.9：训练标签与执行政策一致性实验

协议登记日期：2026-10-20。所有2022–2026年历史均已查看，本次仅为机制探索，不能称独立盲测。V0.8 DAY1和冻结账户不切换模型。本轮不做组合优化，不搜索参数。

## 固定比较

- baseline：已核验V0.8，V2收益门槛0.5%＋原LambdaRank分数。
- gate_only：只把V2的训练目标改为下述政策净收益；排名器仍用原年度模型预测。
- both_aligned：V2与LambdaRank同时采用政策标签；特征、模型超参数与年度滚动边界保持不变。
- 每个版本每时期另列双倍滑点、3个预先固定的同日同候选数随机对照（2026102001、2026102002、2026102003），以及现金。
- 2022–2025连续账户、2026至10月13日独立账户；均3万元、无现金利息、同一V0.8执行规则和费用。主比较共32个情景。随机失败路径保留，不能剔除后声称显著。

## 政策标签

对原411295条候选逐一考虑“空账户、单个信号”的反事实交易。信号日广度不足0.45或已知候选不足100时，标为门控关闭、不产生收益标签；候选本身不因未来信息删除。训练标签只在交易上下文可确定时有值。

按信号日广度预先确定5500/7500元预算，收盘价＋3%限价、100股整手，下一市场交易日开盘尝试进入；使用V0.8的8/12日动态持有、波动率退出、保本/盈利锁定、峰值回撤及次开盘执行规则。入场不可成交、持仓缺行情、异常参考价、未完成退出等保留原因且不作已实现收益。最长退出观察窗为入场后12＋15个市场交易日。

涉及登记、除权、付款或送转上市的区间保守不标记，以免价格标签错误归因；账户回放仍完整使用规范化公司行动。这是与退出政策一致的单笔标签，并非完整多持仓组合价值函数。账户约束导致拒单时，账户结果仍可能不同于单笔标签。

每年训练只取信号日及真实label_end早于该年起点的已完成事件。无额外五日embargo，不虚称存在。重叠事件不是独立样本。

## 必做验证及停止条件

1. 标签生成器与真实V0.8账本按固定种子抽样逐笔核对，包含不同退出类型；任何不一致先停止。
2. 相同特征与训练参数，保存全部年度权重、标签统计、模型输入及源码哈希。
3. 两个历史时期都须优于baseline净收益，最大回撤不恶化，并在双倍滑点下仍有改善，才保留为下一轮候选；若改善不一致，结论为未通过，不改门槛继续追结果。
4. 同时报胜率、笔数、成本、暴露、随机范围和失败路径；不过度解读3个随机种子。

验收通过也不自动替换DAY1；新的未来观察需另行冻结。不通过则保留负结果，继续V0.8的既有观察。
