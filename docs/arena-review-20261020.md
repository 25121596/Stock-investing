# 竞技场审查：2026-10-20

范围：arena.py、直接依赖的执行引擎及当前 results/arena 导出。只读审查和小型合成复现，没有重跑完整比赛，没有修改模型、DAY1记录或现有竞技场导出。

结论：当前是历史回测汇总原型，尚不能据此认定冠军具有未来盈利优势。以下按影响排列；并非指控作者蓄意造假。

## 1. P1：回退到不拦截数据异常的旧引擎

位置：arena.py:90–93；experiment_super_v5_maxprofit.py:48；experiment_super_v7_regime.py:67。

四个策略调用 SuperV5MaxProfitReplay / SuperV7RegimeReplay，重写 run() 后绕过基础引擎持仓报价及公司行动参考价诊断，未使用 VerifiedV08Replay 的拦截。实际复现：三日行情，第二日买入，第三日删除持仓报价，旧引擎继续运行且 warnings=[]；第三日价格和参考价从10同时变5且无公司行动，也继续运行且 warnings=[]。相同输入的 VerifiedV08Replay 分别抛出 missing_held_stock_quote 和 unexplained_adjustment。

影响：异常数据可进入收益和排名且不被标记。这里只证明防线缺失，未证明现存竞技场结果恰好含这些异常。应恢复统一质量检查，质量失败的场次禁止上榜，并导出警告。

## 2. P1：2026策略年化被按四年计算

位置：experiment_super_v5_maxprofit.py:186；arena.py:108–119。V7继承该 summary()。

当前导出实际覆盖2026-01-05至2026-10-13，185个交易日、281个日历日。V0.8累计收益17.3370%，显示CAGR 4.07796%，恰为收益倍数开四次方减一。按首末净值日期间隔计算约23.0986%。后者只是统一日期算法的演示，不代表未来预期收益。现金及指数却使用242/交易日数年化，导致跨选手口径不一致，卡玛比率随之失真。

应对全部账户采用同一初始时点、同一实际跨度；跨度不足时留空。

## 3. P1：all模式第二轮覆盖第一轮

位置：arena.py:193–196、312–314。两次 run_tournament() 均写固定的 leaderboard.csv、equity_curves.csv、dashboard.html。当前目录只有这三项，净值只含2026。无逐次运行目录，也不保存成交、持仓、公司行动账本和输入哈希。

影响：默认跑两轮只能保留最后一轮；再次关闭现金运行也会覆盖已有结果。应使用唯一运行目录，按时期和场景分文件，并保存账本、参数和数据/源码哈希。

## 4. P1：随机对照未实现，证据标签过强

位置：arena.py:11、89–94、247、291、313。文件声称三随机账户，但参赛列表只有四模型加现金和指数，共六项；没有随机选股或种子。2026又被称作 BLIND FORWARD，而它是从既存预测CSV读取并重放已查看的历史；没有事前封存和未来逐日记录流程。

影响：无法用本榜判断排名器是否超过同机会的随机选股，也不能将此当作DAY1之后的独立验证。应明确标为已查看历史重放，增加事前固定种子的匹配机会随机账户，移除绝对无未来偏差保证。

## 5. P2：现金收益公式与计息次数不一致

位置：arena.py:129–133；experiment_super_v5_maxprofit.py:44、125–128。

策略以0.022/242每日计息，含首日；基准以(1.022)^(1/242)-1计息，指数从0开始，少计一天。当前第一日策略现金30002.7272727元，纯现金基准30000元。因此模型和基准并未使用同一现金收益过程。GC001只是命名，代码没有行情、订单和回购到期流程，不宜称作已模拟的回购成交。

应复用统一现金模块；固定利率明确为假设，另列无现金收益的主结果。

## 6. P2：等权指数不是300股买入持有账户

位置：arena.py:148–186。每天对当日存在的有限 pctChg 取均值再复利，相当于动态可用样本的每日等权收益序列。没有实际持股、整手限制、再平衡成交和费用，也没有固定权重的买入持有账本。缺报价股票会自动退出当日分母。

影响：可以用作清楚标注的参考指数，不能描述为同样3万元可执行的300股买入持有。首日收益包含前一收盘到当日收盘区间，但策略初始时点没有同步定义。指数回撤和日收益又从首日净值开始，遗漏初始本金到首日的变动。

## 7. P2：不可比较和虚构的指标被放进统一榜单

位置：arena.py:140–144、184–186。现金胜率固定100%、Calmar和Profit Factor固定99；指数“平仓笔数”写死300，胜率实际为上涨日比例；模型胜率则为盈利平仓笔数比例。

影响：同列数字含义不同，现金100%胜率不是交易胜率，300也不是平仓数。不可定义的值应显示N/A，分开展示交易指标和参考序列指标。

## 8. P2：文档所列命令均不可用

位置：arena.py:16–18、301–305。真实执行 `.venv/Scripts/python.exe arena.py leaderboard` 返回退出码2和 unrecognized arguments: leaderboard。run/dashboard同样无对应子命令。应实现子命令或将使用说明改为实际参数。

## 9. P2：自定义日期默认被忽略，移动目录后部分路径失效

位置：arena.py:36、44–46、302–316。默认mode=all，即使传start/end也运行两个写死时期；mode=2026也忽略日期。ROOT写死D盘，预测文件却相对当前工作目录读取，换目录启动可能找不到或读错输入。

应将ROOT设为脚本目录；输入均使用显式路径；不适用的日期参数应拒绝而不是静默忽略。

## 验证边界

已完成源码审查、当前CSV指标重算、两种数据异常的合成复现和命令行失败复现。没有重新训练或完整重跑所有参赛者，未审计V3训练数据和特征的完整时间血缘；因此不能据此保证所有信号均无泄漏，也不能断言当前总收益算错或存在人为伪造。修复优先级：质量拦截和账本保存 → 统一统计时点 → 保留各轮输出 → 正确随机对照与展示标签。
