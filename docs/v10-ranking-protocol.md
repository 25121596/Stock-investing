# V0.10排序底层实验：事前固定方案

2026-10-21。此协议在生成本轮模型分数/账户结果之前保存。所有2022—2026行情都已查看，此轮属于历史开发筛选，不是新盲测，也不保证会找到合格升级。

## 问题与范围

原V0.8按日对旧10日净收益做五分位相关度，最高20%同标签；实际门控后最多买1/2只，LambdaRank未显式设置截断，默认30。以标签分辨率及损失函数为重点，避免改变样本域和执行目标同时混杂。

固定原37项特征、原411295行候选、可用训练样本、V2收益预测>=0.005门控、广度>=0.45且池>=100、原每日1/2笔限制、3万元、5500/7500预算、最大仓位、次开盘限价、T+1、止盈止损/8或12日退出、公司行动及全部费用。无现金利息，滑点正常万5及压力万10。使用VerifiedV08Replay并独立重建账本。

按2022—2026逐年扩窗；训练标签结束日严格早于当年1月1日。保留原实现的日期边界，不谎称有额外五日隔离。训练数据不做未来全样本填充；新微观特征应全有限，早期非有限基础特征行按原规则排除。验证训练行数和特征哈希与原V0.8年度记录一致。预测覆盖与原298754行完全相同。

## 第一阶段：2×2消融

基线直接使用已保存年度权重重新推断并验证分数一致。原模型其他参数不变，仅统一使用4线程以控制资源。

1. `top_focus`：原五分位标签，LambdaRank截断=5。实际目标最多2名，加3是温和的顶部范围。
2. `tail_labels`：只将训练标签细分为收益百分位<=50%、50–80%、80–90%、90–95%、95–98%、98–100%，取等级0—5、gain=[0,1,3,7,15,31]；不改默认截断。百分位使用同一训练日平均秩，收益相同者不会因代码排序被赋不同标签。
3. `tail_top_focus`：同时采用上述两项。

## 预定第二阶段（仅第一阶段无合格版本时执行）

不是根据输赢再调门槛：两个独立机制及参数在此固定，不再扩展。

4. `tail_xendcg`：细分标签不变，以rank_xendcg替换目标；不传LambdaRank专用截断和gain参数，其余模型容量、轮数和随机种子同原排序器。参考LightGBM官方说明及论文An Alternative Cross Entropy Loss for Learning-to-Rank。
5. `return_regressor`：用原V2 Huber回归参数（200树、深度4、11叶、学习率0.02、lambda15、最小叶250、固定种子）在相同37特征/同训练行的旧净收益clip[-0.2,0.2]上训练，直接按预测净收益排序；门控依然使用冻结V2，不用新分数改变交易日期。它测试基数收益目标相对粗分位排序是否更有用，不做阈值搜索或校准。

最多五个新机制版本、每版五年权重，不搜索参数、种子、混合权重、持有期和新增特征。所有模型与失败保留。

## 验收

主比较：2022—2025连续账户、2026独立3万元账户截至10月13日。候选需同时满足两个时期：正常成本累计净收益严格高于V0.8；最大回撤不恶化；双倍滑点收益严格高于同样受压的V0.8。正常及压力账户质量检查和独立账本审计均必须通过。未满足任何一项都不称为“超过V0.8”。

报告交易数、胜率、费用、平均暴露、逐年表现及最大1/3/5笔赢家贡献。对固定门控以20个事前种子匹配信号日及候选数进行共享随机比较；V2门控未改，因此所有候选使用相同随机对照，不能当作额外独立样本。无效随机账户保留失败，不补种子；随机统计只作条件描述，不做显著性或未来胜率保证。

若多版本合格，报告全部；按两个时期相对基线收益改善的较小值排序，仅用于决定未来旁路观察优先级。开发选择偏差明确披露。若无版本合格，如实报告失败，不自动扩大搜索范围。

本轮不会更改已有冻结权重、DAY1、RQAlpha运行队列或模拟执行代码。即便历史达标，也不自动替换运行中的V0.8，必须另建未来观察版本。
