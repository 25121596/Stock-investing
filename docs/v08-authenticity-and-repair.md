# V0.8真实性核验与修复结果（2026-10-20）

## 判断

**目前没有发现预测分数或主表历史收益凭空编造的证据。发现了不实的验证表述、说明书数值不一致和实现缺陷；不能凭这些材料判定制作者的主观造假意图。**

本次重新训练、重算特征、复核行情/标签、修复执行保护并建立独立模拟版本。未改写Gemini原模型脚本、历史结果和旧未来账户。旧“冻结”目录和错误说明保留作为原始证据；正确版本为 `v08-codex-frozen-v3`。

|---|---|

| 预测CSV真实性 | V2、V0.8各298754行，共597508个分数；日期/股票键、数值逐值一致，最大绝对差0 |

| 缺失值处理 | 原代码全期中位数回退所涉10项特征缺失行数均为0，本次没有实际触发这条潜在泄漏路径；新日推理遇到非有限值直接阻断 |
| 标签重算 | 按年固定随机抽取175条，含无法标记的样本；净收益和标签终止日均匹配。此为抽样，不是全量标签认证 |

上述检查支持本地模型、特征、预测和模拟利润之间有可重现的链条，不能证明每条供应商数据真实无误，也不证明未来盈利。

## 经济结果与随机对照

3万元虚拟账户，扣除实现的交易费用、现金利息为0；均为累计净收益，非年化。

| 情景 | 2022–2025 | 2026截至10月13日 |
|---|---:|---:|
| 正常滑点 | +42.79%，回撤8.32% | +15.73%，回撤3.99% |
| 双倍滑点 | +37.70%，回撤11.39% | +15.48%，回撤4.08% |

本次提前固定100个随机种子，各时期都从相同当日合格池无放回选股，匹配日期/候选数，使用相同费用和仓位规则。实际成交和资金暴露仍可能不同，所以不是完全相同风险的配对实验。

- 2022–2025：100次中97次能完成，5次收益高于模型；另3次因退市持仓缺行情被质量检查阻断。失败路径完整保留，不排除后声称正式显著。把失败路径的未知收益算在任一端，简单加一法尾部比例范围约5.94%–8.91%；这不是修正过策略选优的统计检验。
- 2026：100次均完成，没有一次高于模型；名义加一法经验p约0.0099。**没有校正此前多版本/多参数选优**，不能据此认定真正未见年份的显著超额。
- 正常滑点、不计现金利息，旧期52赢/109笔，2026为8赢/13笔；合计约49.18%，未达到整体胜率超过60%的目标。2026前三大盈利交易约占净利72%，证据集中。

## 确认的错误与已采取的修复

1. 原报告将反复查看、迭代选优后的2026称为“盲测”，并称最高样本外冠军。新报告统一标注已查看历史；新规则的事前记录单独立账。
2. 原冻结版只有说明JSON，没有可推理权重。现保存10个年度模型、训练边界、输入/标签哈希及加载一致性；新冻结线固定两个2026权重、源码、特征顺序、依赖及协议，并验证从日线到双模型输出的闭环。
3. 原循环漏掉持仓行情缺失和异常除权参考价检查。核验版恢复并升级为阻断；合成异常价格减半、缺持仓行情测试通过，随机对照的3次阻断也展示了实际作用。
4. 原摘要把所有周期按四年年化。核验版按实际跨度生成CAGR/Calmar，零跨度不伪造年化。
5. 原说明胜率、利息、费用来自不同结果。核验版从保存的真实账本输出JSON，不手填收益；不包含假设的固定2.2%现金利息。
6. 原自验无条件打印“全部通过”、随机从整个池有放回抽股票。新检查在关键失败时中断，预注册随机池匹配，并报告所有失败路径，不将p值等同完整验证通过。

保存权重属于不改变预测的透明插桩：只在拟合后新增保存/核验步骤，并将输出改到新目录。原始源码与插桩源码均保留；没有为了匹配预测修改参数或挑训练种子。

## 新版本的状态与限制

`v08_paper_forward_v3.py` 已创建独立的3万元主账户、3个固定随机对照和现金对照。原三策略未来模拟账户保持不变。最早信号日为2026-10-20；初始化不能当未来业绩，实际封存数量以状态页为准。当前仅支持手动运行，不设自动任务、不接券商。

最终发布版本为v3。v1/v2仅是本轮集成测试前的调试冻结材料，未形成未来预测业绩；默认入口 `v08_paper_forward.py` 已转到v3。集成测试补齐了账户摘要字段，并把首日或零波动时无定义的Sharpe/Sortino保存为null，而不是NaN或伪造统计值。v3实际冻结代码重放四组主要情景后，收益与此前逐值一致。

最高计划仓位90%、单笔最多7500元，明显高于旧观察线；该风险参数仅保留在虚拟账户。没有足够未来交易前，不将历史收益作为实际资金的收益预期。
